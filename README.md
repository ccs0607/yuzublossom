# 月满人间 · 中秋来信

以深靛夜色、暖金月光和细线装帧设计的中秋互动页面。原生 HTML / CSS / JavaScript，无框架、无需构建、无远程素材依赖。

## 本地运行

```sh
python -m http.server 8000 --bind 127.0.0.1
```

访问 http://127.0.0.1:8000/ 。可以直接部署到 GitHub Pages 等静态托管服务。

## 页面与交互

- 约 13.4 秒的完整开屏：星河、凝光、月升、云起、月影、婵娟、团圆、相逢；随后过渡到新版首页。支持跳过、Escape 退出和页尾重播。
- 月影与嫦娥显现使用同一张人物图，避免图像切换造成跳位；月亮、流云、人物、飘带和书法题字独立运动。
- Canvas 与所有图层共用时间线，切到后台时同步暂停。跳过或重播会取消整段动画；减少动态效果时直接显示首页，锚点链接直接抵达对应章节。
- 进入序幕前解码分层资源，加载失败或超时自动回到首页；首页继续提供滚动显现与轻量视差。
- 澄月 / 桂雨 / 灯海三种氛围，月光涟漪与夜空星尘。
- 月亮位置根据图片的 `object-fit`、`object-position`、缩放和视差实时换算，在手机与桌面保持一致。
- 心愿编辑、快捷祝福、天灯放飞及最近三条心愿展示。最多保存 20 条心愿与累计数量。
- 五首署名月夜诗句，可切换、收藏并写入贺卡。
- 自定义收件人、落款、祝福，预览并下载 1080×1620 PNG 月信。
- 沉浸赏月模式，可通过按钮或 Escape 退出。
- 用户主动开启的 WebAudio 合成音效，无音频下载。
- 原生 dialog、键盘操作、焦点恢复、ARIA 状态及减少动态效果适配。
- Canvas 离屏与后台暂停，限制粒子数量，设备像素比最高为 2。

心愿和收藏只保存在浏览器 localStorage，不发送到服务端。存储不可用时自动降级为本次浏览记录。

## 资源

主画面沿用 `assets/generated/final_scene.webp`。开屏重新使用原有的月亮、远近云层、嫦娥、飘带与“中秋”题字素材。仅在播放开屏时加载这六张分层图片，原始素材全部保留。

本轮自行绘制的本地 SVG：

- `assets/crafted/moon-seal.svg`：月印与站点图标。
- `assets/crafted/lantern.svg`：天灯、仪式卡及祈愿弹窗插图。
- `assets/crafted/osmanthus.svg`：桂枝插图。

信封、轨道装饰和纸张使用 CSS 绘制；桂花、星光使用 Canvas 绘制；贺卡使用 Canvas 在本机合成。

## 文件

- `index.html`：首屏、仪式卡、诗句、祝福及弹窗。
- `style.css`：视觉系统、动效、响应式和无障碍样式。
- `app.js`：交互、坐标换算、粒子、存储、音效及贺卡导出。
- `intro.js`：开屏图层编排、统一时间线、资源加载、后台暂停、跳过与重播。
- `script.js`：历史版本脚本，当前页面不引用。
- `tools/smoke_test.py`：浏览器端流程验证与截图。
- `tools/intro_test.py`：开屏逐阶段、手机和横屏布局、跳过重播、异常资源与键盘验证。

## 验证

测试使用 Python Playwright 与本机 Edge；仅开发验证需要安装 Playwright：

```sh
python -m pip install playwright
python tools/smoke_test.py
python tools/intro_test.py
```

可用 `BROWSER_PATH` 设置 Chromium 可执行文件路径，`TEST_URL` 设置测试地址。运行前应启动本地静态服务。

覆盖实际下载、心愿持久化、诗句收藏、弹窗键盘操作、减少动态效果、存储异常与输入转义；检查 320、390、768、1024、1920 像素宽度的溢出和月亮特效位置。结果与截图保存在忽略提交的 `output/qa/`。
