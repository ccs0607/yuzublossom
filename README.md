# 月满人间 · 中秋互动贺卡

当前版本已重构为带完整叙事开场的纯前端中秋贺卡，直接复用本机 `assets/hero.png` 主视觉，不依赖远程图片和第三方框架。

## 开场动画顺序

1. 黑夜星辰
2. 星光向月轮聚拢
3. 月轮从云后升起
4. 月面逐渐亮起
5. 云层掠过
6. 嫦娥轮廓先出现
7. 人物完整显现
8. 桂花与衣带局部动态
9. “中秋”主视觉完成显现
10. 进入互动状态

## 互动

- 跳过开场 / 重播完整动画
- 输入一句心愿并放飞天灯
- 点击“轻触明月”触发月光与星尘反馈
- 完成开场后点击任意夜空区域触发星光回应
- 桌面端鼠标移动提供轻微视差

## 文件

- `index.html`：页面结构
- `style.css`：场景分层、阶段转场、云雾、飘带、天灯和响应式样式
- `app.js`：开场时间线、Canvas 星空、交互与粒子
- `assets/hero.png`：当前主视觉
- `assets/scene_soft.png` / `assets/scene_alt.png`：备用主视觉

旧版 `script.js` 保留在仓库中但当前页面不再引用。

## 本地运行

```bash
python -m http.server 8000
```

浏览器访问 `http://127.0.0.1:8000/`。
